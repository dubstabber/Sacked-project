# Sacked — Godot reimplementation

A reimplementation of **Sacked** (2002–2003), the isometric office-prank game, in Godot 4.7.
It plays the original campaign and uses the original art, sound and text. No code from the
original game's ODIN_ENGINE is involved. The game's behaviour was recovered by reverse
engineering the original executable, and every recovered rule is written up in [`docs/`](docs).

## Download
Ready-to-play builds are on the **[Releases page](https://github.com/dubstabber/Sacked-project/releases)**.

## What's in it

- All 21 campaign levels on the original triangular level tree, in both game modes: the
  time game and the points game.
- Both player characters, Jo Bless and Anne Employed, and coworkers who follow their own needs
  around the office.
- Pranks, the HUD lamp abilities, getting caught, the memory duel, the level results and the
  highscore board.
- Sound setup, coworker names and a saved profile, as in the original.
- Polish, German and English text. The Polish and German come from the two retail builds.
- Wide-screen support: a wider window shows more of the office instead of stretching it.
- Custom levels, built in the Godot editor from the game's own art and played from the main
  menu. See [`docs/map-authoring.md`](docs/map-authoring.md).

## Controls

| Input | Action |

| Hold right mouse button, or arrow keys | Walk |

## Running from source

The images, sounds and fonts are stored with [Git LFS](https://git-lfs.com), so install it
before cloning:

```bash
git lfs install
git clone https://github.com/dubstabber/Sacked-project.git
```

Then open the project in [Godot 4.7](https://godotengine.org/download) and press Play, or
start it from the command line:

```bash
godot --path Sacked-project          # run the game
godot -e --path Sacked-project       # open the editor
```

## Development

```bash
python3 tools/run_checks.py               # import, every test, every exporter --check
python3 tools/run_checks.py --filter npc  # only the steps whose label contains "npc"
```

`run_checks.py` uses the Godot binary in `$GODOT_BIN`, or else the newest
`Godot_v*-stable_linux.x86_64` in the project root. Tests are headless Godot scripts
(`tests/check_*.gd`) and Python `unittest` files (`tests/test_*.py`).

The campaign scenes, object prefabs and level manifests are generated by the importers in
[`tools/`](tools), so don't edit them by hand. The importers read the original game's files,
which are not in this repository. Without them, the checks that compare against the originals
are skipped.
